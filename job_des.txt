# Machine Learning Engineer (2026)

## About the Role

We are looking for a passionate Machine Learning Engineer to design, build, and deploy AI-powered applications. You will work closely with software engineers, data scientists, and product teams to develop scalable ML systems, LLM-based applications, and intelligent automation solutions. The ideal candidate enjoys solving real-world problems using modern AI technologies and writing production-quality code.

---

## Key Responsibilities

* Design, train, evaluate, and deploy Machine Learning models.
* Build and maintain end-to-end ML pipelines.
* Develop Retrieval-Augmented Generation (RAG) systems using Vector Databases.
* Fine-tune and optimize Large Language Models (LLMs) when required.
* Build AI agents and multi-agent workflows using frameworks such as LangGraph or CrewAI.
* Develop REST APIs using FastAPI for AI services.
* Implement prompt engineering and structured outputs for LLM applications.
* Work with embeddings, semantic search, and document retrieval systems.
* Optimize model latency, inference speed, and cloud deployment costs.
* Monitor production ML models for performance, drift, and reliability.
* Collaborate with backend developers and product teams to integrate AI features into applications.
* Write clean, maintainable, and well-tested Python code.
* Deploy AI applications using Docker and cloud platforms.
